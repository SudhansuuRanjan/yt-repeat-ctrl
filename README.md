# YouTube Repeat Controls

Adds the "Repeat Once" (🔂) and "Repeat Toggle" (🔁) buttons that are missing from the native YouTube player.

This extension places the two most-needed repeat functions directly into the player control bar, right where they belong.

-----

## Features

  * 🔁 **Toggle Repeat:** Loops the video indefinitely. This setting persists even when you navigate to a new video.
  * 🔂 **Repeat Once:** Plays the video one more time, then automatically turns the repeat setting off.
  * **Native UI:** Icons and position perfectly match the native YouTube player theme (light and dark).
  * **Lightweight:** The toolbar icon activates (lights up) *only* when you are on `youtube.com` and remains dormant on all other sites.

-----

## Install (Manual / Sideloading)

1.  Download the complete project folder (with `manifest.json`, `.js` files, and the `icons` folder).
2.  Go to `chrome://extensions` in your Chrome browser.
3.  Enable **"Developer mode"** (using the toggle in the top-right).
4.  Click the **"Load unpacked"** button.
5.  Select the project folder you downloaded. The extension is now installed.

-----

## How to Use

1.  Go to any YouTube video.
2.  The two new repeat buttons will appear in the player controls (next to the Settings gear).
3.  Click 🔁 for an infinite loop or 🔂 to repeat the video just once.
